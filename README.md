# Unit Converter 🔄
A simple Python CLI tool to convert between common units.

## Features
- KM ↔ Miles
- KG ↔ LBS  
- Celsius ↔ Fahrenheit
- Input validation + loops until exit

## How to Run
```bash
python converter.py
```

## Demo
Menu-based converter with 6 options. Handles invalid input gracefully.
