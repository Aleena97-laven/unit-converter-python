# Unit Converter 🔄
A simple Python CLI tool to convert between common units.

## Features
- KM ↔ Miles
- KG ↔ LBS  
- Celsius ↔ Fahrenheit
- Input validation + loops until exit
- USD ↔ INR with live exchange rates via API
- Error handling for API failures

## How to Run
```bash
pip install request
python converter.py
```

## Demo
Menu-based converter with 8 options. Handles invalid input gracefully. Uses live API for currency rates.
